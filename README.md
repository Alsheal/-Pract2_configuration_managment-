# Визуализатор графа зависимостей

## Описание проекта

**Визуализатор графа зависимостей** — учебный проект на Python, предназначенный для анализа зависимостей программных пакетов, построения направленного графа зависимостей и его последующей визуализации в формате SVG.

Проект разрабатывается в рамках дисциплины «Конфигурационное управление». Вариант № 26.

Разработка разделена на пять этапов. На текущий момент реализованы и протестированы первые четыре этапа:

1. Конфигурация приложения и интерфейс командной строки.
2. Загрузка тестового репозитория и анализ зависимостей.
3. Построение направленного графа зависимостей.
4. Визуализация графа и формирование SVG-файла.

На текущей версии проекта успешно проходят **66 автоматических тестов**.

## Цель проекта

Разработать приложение, которое позволяет анализировать зависимости выбранного программного пакета, строить граф зависимостей и представлять результат в виде графического изображения SVG.

## Этапы разработки

### Этап 1. Конфигурация и интерфейс командной строки

**Статус: завершён.**

Реализованы следующие возможности:

- загрузка параметров из YAML-файла;

- проверка версии пакета в формате SemVer;
- проверка режима работы с тестовым репозиторием;

- настройка максимальной глубины анализа зависимостей;

**Статус: завершён.**

Граф представлен структурой данных, содержащей имя корневого пакета, список вершин и список направленных рёбер.

Каждая вершина содержит имя пакета, версию и глубину. Каждое ребро содержит исходный и целевой пакеты.

## Конфигурация приложения

Настройки приложения хранятся в файле `config.yaml`.

Пример конфигурации:

```yaml
package_name: serde
repository: tests/fixtures/repository.yaml
test_repository_mode: true
version: "1.0.0"
output_file: dependencies.svg
max_depth: 3
```

### Описание параметров

| **Параметр** | **Тип** | **Описание** |
| ---------------------- | ------------------- | ----------------------------------------------- |
| `package_name` | Строка | Имя анализируемого пакета |
| `repository` | Строка | Путь к репозиторию пакетов |
| `test_repository_mode` | Логическое значение | Включение режима работы с тестовым репозиторием |
| `version` | Строка | Версия пакета в формате SemVer |
| `output_file` | Строка | Имя выходного SVG-файла |
| `max_depth` | Целое число | Максимальная глубина анализа зависимостей |

## Пример работы

### Этап 1. Проверка конфигурации

Приложение получает настройки из `config.yaml` и проверяет их корректность.

Пример конфигурации:

```yaml
package_name: serde
repository: tests/fixtures/repository.yaml
test_repository_mode: true
version: "1.0.0"
output_file: dependencies.svg
max_depth: 3
```

### Этап 2. Анализ зависимостей

На втором этапе приложение загружает тестовый репозиторий и определяет прямые и транзитивные зависимости выбранного пакета.

Например, если пакет `serde` зависит от `syn` и `quote`, а пакет `syn` зависит от `unicode-ident`, анализ позволяет определить:

- прямые зависимости: `syn`, `quote`;
- транзитивную зависимость: `unicode-ident`.

### Этап 3. Построение графа

На третьем этапе результаты анализа преобразуются в структуру направленного графа.

Пример логической структуры графа:

```text
serde
├── syn
│   └── unicode-ident
└── quote
```

Вершины содержат имя пакета, версию и глубину. Рёбра показывают направление зависимости от пакета к его зависимости.

### Этап 4. Создание SVG-визуализации

На четвёртом этапе построенный граф преобразуется в графическое изображение формата SVG.

Визуализатор размещает пакеты на изображении с учётом глубины зависимостей. Каждый пакет отображается в виде блока с названием, версией и глубиной.

Связи между пакетами отображаются направленными линиями со стрелками.

Корневой пакет выделяется отдельным цветом.

Результат сохраняется в файл `dependencies.svg`.

Для открытия созданного файла в Windows из WSL можно использовать команду:

```bash
explorer.exe dependencies.svg
```
